# AI作業パネル v1.0

Work Dockの独立した作業ページ。静的HTML/CSS/JavaScriptのみで動作します。

## できること

- 6種類の依頼ボタン（文章整理、返信、広告文、要約、進め方、自由依頼）から、案件の前提を含む依頼文を組み立ててコピー。
- 案件別に目的、いつもの条件、決定事項、引き継ぎメモを保存。選択中の案件、作業の種類、素材、追加条件、貼り付けた回答を自動保存。
- 回答を貼り付けると、短く、やわらかく、結論から、別案、具体化、抜け・矛盾チェックの6種類の修正依頼をコピー。最後にコピーした元の依頼を保持し、現在の案件前提も含めます。
- 作業履歴を案件ごとに30件保存・再開。素材、追加条件、回答、保存時の依頼文を保持。再開時の案件前提は現在の内容を使用。
- 全案件のJSONバックアップ、検証付き復元。別タブ競合時は自動保存を停止して入力を保護。保存失敗時は画面内の入力を維持してバックアップを案内。

## 保存・制限

- 専用localStorageキー `osanai-ai-panel-v1`、schema `app: osanai-ai-panel, version: 1`。既存Work Dock/CRM等の保存キーを読み書きしません。
- 案件最大100件。素材30,000文字、回答50,000文字、追加条件5,000文字、案件の前提等各12,000文字。ブラウザの保存容量によっては上限前に保存できなくなります。
- Work Dock本体のバックアップには含まれません。このパネルの「バックアップ」を使用してください。端末間の自動同期はありません。
- **AI API接続なし。回答生成・自動要約・自動送信は行いません。** AIへの依頼文貼り付け、回答の貼り戻し、引き継ぎノートの入力は利用者が行います。
- 外部ライブラリ、外部フォント、解析タグ、送信先の外部AIリンクはありません。コピーだけで別ページを開きません。入力内容をネットワークへ送信しません。
- 新規作業・案件/履歴削除・履歴からの再開・バックアップ復元は確認後に実行します。
- コピーAPIが失敗した場合は手動コピー用の全文を表示し、成功とは報告しません。

## 検証

Gitルート外の `../checks/ai-panel.cjs`（プロジェクトルート基準）で4幅のブラウザ検証、保存・バックアップ・競合・容量不足・破損復旧・コピー拒否・HTML注入対策・既存データ不変を確認します。実業務データは検証・公開に含みません。
