# Work Dock

サイト・今日のタスク・定型文・メモをまとめた業務ショートカットアプリ。無料のGitHub Pagesで動作し、外部ライブラリやサーバーは不要です。

- サイト名またはお気に入りの「開く」で別タブに移動。
- 今日やることは1行入力で追加し、チェックで完了。未完了は翌日も表示。「すべての予定」で未来のタスクを確認。
- 定型文とメモは一覧からコピー。「全文」で内容を確認・選択。
- ☆でお気に入りに固定。上部からサイトを開く、本文をコピー、タスクを完了。
- 検索はタイトル・本文・URLが対象。通常一覧は20件、お気に入りは12件ずつ追加表示。
- 削除は確認後に実行。直後の「元に戻す」で取り消せます。次の保存・再読み込み・別タブ更新で取り消しは終了。
- バックアップはJSONで保存・復元。復元は全置換で、確認が必要です。

データはこの端末・ブラウザのlocalStorage（`osanai-work-dock-v1`）にのみ保存されます。ログインや自動同期はありません。ブラウザのデータ削除前にはバックアップしてください。プライベートブラウズでは終了時に消える場合があります。登録内容をサーバーへ送信する機能はありません。実業務データは公開リポジトリに含めません。

GitHub Pagesは同じホストの他アプリとブラウザ保存領域のオリジンを共有します。専用キーを使用し、他アプリのキーは読み書きしません。

公開方法: mainブランチのルートをGitHub Pagesに指定。`.nojekyll` で静的ファイルをそのまま配信。
