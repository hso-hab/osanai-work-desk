# Work Dock v2.3 — 業務ホーム

今日の仕事を始め、主要数値を確認し、次の作業まで進めるブラウザ内の業務ホーム。無料のGitHub Pagesで動作する静的HTML/CSS/JavaScriptです。

## ホームでできること

- 今日までの着手可能な未完了タスクを表示。初期状態は期限切れを先頭に並べ、赤枠・警告文で強調。今日のタスクを1行で追加。
- CRMの要対応、LP Noteの未入力・修正候補も「今日やること」の直下に表示。
- CRM・LP Note・広告管理（Ad Note）の主要数値を、各アプリを開かずに表示。各カードの「開く」で1クリック移動。
- 「着手」で関連アプリや登録項目へ移動。タスクの完了後は「次の作業へ」。関連先がないタスクは本文を開いて「完了して次へ」。
- 朝・日中・締め作業の定型作業。グループ名、作業名、起動先、順番を編集でき、グループの追加・削除も可能。チェックはその日のみ有効で翌日は未完了に戻ります。これは日次チェックです。タスクの自動作成は別の「繰り返し」設定で行います。
- 最近開いたサイトと、★優先・利用回数順の定型文をホームに集約。Work Dock内の起動のみを記録し、ブラウザ全体の履歴は取得しません。
- 定型文はカテゴリとキーワードで絞り込み、1クリックコピー。カテゴリ名も検索対象。旧データは「未分類」。
- メモからタイトル・本文を引き継いでタスク化。元のメモは保持し、同じメモに未完了タスクがある場合はその編集画面を開いて重複作成を防ぎます。
- PCは3列の業務ホーム、スマホは今日の作業・最近のサイト・定型文から順に表示。多数の項目はホーム内のスクロールと追加表示に対応。

## 連携する数値

| アプリ | 読み取る専用キー | 表示 |
| --- | --- | --- |
| CRM | `osanai-line-crm-demo-v1` | 未対応、今日までの要対応、担当未設定 |
| LP Note | `osanai-lp-note-v1` | 今日未入力、修正候補、今日の入力済み利益 |
| 広告管理 | `osanai-ad-manager-v1` | 今日の広告費、成果数、利益 |

同じブラウザ・同じオリジン（公開版では `https://hso-hab.github.io`）の保存データを**読み取り専用**で集計します。別端末、別ドメイン、CRMサーバー版は対象外です。初期データ生成、元アプリへの書き込み、ネットワーク経由の業務データ取得・送信は行いません。

データなし・読み取り失敗・今日の実績未入力を区別します。利益等の未入力は「—」で、実際に入力した0とは区別。アプリ間の数値は合算せず、LP利益は売上−広告費−その他費用、広告管理は元アプリ同様に手入力利益があれば優先します。既存のCRMサンプルが保存されていれば、その保存内容も集計対象です。

ページ表示時、元アプリの別タブ保存時、ウィンドウ復帰時、「更新」、日付変更時に再集計します。表示時刻は読み取り確認時刻で、元データの更新日時ではありません。

`vendor/lp-core.js` と `vendor/ad-core.js` は各アプリの公開中の集計・検証コードを同一内容で同梱したものです。2026-09-13のLP Note v1.2 / Ad Note v1.1と一致。元アプリの保存形式変更時には互換性を再確認してください。

## 既存機能とデータ保護

サイト・タスク・定型文・メモの全件管理は「すべての登録」か種類別ナビへ。お気に入り、横断検索、タスクの日付分類、ドラッグ・上下ボタンでの並び替え、削除確認と直後の取り消し、JSONバックアップ・復元を維持しています。コピーが拒否された場合は本文選択を案内します。

保存キーは引き続き `osanai-work-dock-v1`、基本形式は `{app:'work-dock',version:1,items:[]}`。v1.0/v1.1から登録内容・利用履歴・並び順を保持し、不足初期リンクだけの追加も従来通りです。v2.0ではトップレベル `routines`、項目の任意フィールド `category/actionTarget/sourceId/completedOn` を追加し、バックアップに含めます。旧JSONの復元にも対応します。削除した初期リンクや空にした作業グループを毎回再生成しません。

登録内容はこの端末・ブラウザのlocalStorageに保存。ログインや端末間の自動同期はありません。Work Dockのバックアップには連携元3アプリのデータは含まれません。元アプリのバックアップは各アプリで行ってください。

復元は全置換で確認が必要です。破損元データ保護、容量不足時の保存拒否、未保存入力の破棄確認、別タブの更新を古い入力や作業グループ編集で上書きしない保護があります。削除の取り消しは次の保存（利用履歴を含む）・再読み込み・別タブ更新で終了します。

## 公開

専用リポジトリ `hso-hab/osanai-work-desk` の `main:/` をGitHub Pagesで公開。`.nojekyll` でそのまま配信。業務データ、テスト用データ、バックアップは公開リポジトリに含めません。

## v2.1 順番に進める仕事の流れ

- ホームは期限切れ→今日の順、各グループ内は最重要→重要→通常→期限の古い順。同条件は既存の手動順。先頭を「今やる」で表示し、未来の作業は全タスクへ。各期限グループは最初6件まで。
- 完了直後・完了履歴の「次の作業」から、本文・重要度・関連先・作業セットを引き継いだ新規タスクを登録。期限は今日、繰り返しはなしで開始し、自由に変更できます。
- 毎日・毎週（期限と同じ曜日）は初回タスクの期限から計算。起動時、日付変更時、復帰時に未作成の予定日ごとのタスクを作成します。閉じている間にサーバーが動く仕組みではありません。再開時に空いた日の分も追加し、未完了は保持します。
- 「繰り返し」で停止・再開、今後のタイトル/次回期限/頻度/重要度/資料を変更。今後の設定変更は既存の完了履歴を書き換えません。既存タスクの削除や完了だけでは定期設定は停止しません。
- 作業ごとにURL（20件まで）、定型文、メモ、登録済み項目（50件まで）をまとめます。タスク編集のセット保存、またはホームの「作業セット」から単独作成・編集・削除・起動。タスクへの適用は内容のコピーなのでセットの後の変更・削除ではタスクの資料は消えません。登録済み項目の参照は元項目の最新版を使います。
- 「着手」で資料をひとまとめに表示。サイト一括起動と定型文のコピーに対応。ブラウザが複数タブをブロックした場合は開けた件数を表示し、各リンクで開けます。定型文を複数同時にクリップボードへ上書きしません。
- 今日の進捗 = 今日完了したタスク + 今日の定型チェック / 今日完了 + 今日までの未完了 + 定型チェック総数。過去に完了したタスクは今日の分母に含めません。完了履歴はタイトル・本文・作業メモ・日付で検索、完了日でも絞り込み。完了日なしの旧データは「完了日不明」と表示します。
- 保存キーと基本schemaは維持。任意の `schedules` / `worksets`、項目の `priority/resources/repeatId/repeatDate/followUpOf` を追加。定期作成と次回日付は同じ保存操作で更新。件数上限や保存失敗では元のデータを保持します。旧バックアップも復元可能、停止を含む繰り返し・セットもバックアップ対象。


## v2.2 着手・時間・週の振り返り

- 今日の着手候補は期限切れ→今日、同じ区分では重要度→3日以上動きなし→期限順。待ち・確認待ちと、後日に予定した仕事は除外します。近い期限（3日先まで）と長く動きのない未来の仕事は「早めに確認」に最大3件表示。放置判定は登録日または最後の編集・状態変更・時間記録・繰越から3暦日です。旧版の活動履歴はないため登録日を使用します。
- タスクの「操作」または「着手」から、時間の開始／停止、状態変更、繰り越し。待ちメモと作業予定日は編集で設定。待ち・確認待ちは専用一覧で戻せます。今日の進捗は今日の着手候補を対象とし、待ち・後日予定は別件数を表示します。
- 時間は同時に1タスクだけ計測。別タスク開始で前の計測を保存。リロードやタブを閉じても開始時刻を保持し、再開時に停止できます。完了・待ち化・繰越・削除でも計測停止。同じ端末の時計に基づき、日をまたいだ分はローカル日付ごとに分割。週の集計には停止済み記録だけを含めます。
- 「時間記録・手入力」では今日までの作業日と1〜1440分を追記でき、停止忘れ等は記録削除・手入力で修正できます。進行中の計測自体の取り消しも可能。時計が開始時刻より前に戻った場合は停止を拒否し、取り消し・手入力を案内します。時間記録は最大5万件、保存失敗では元の記録・計測を保持。
- 「もう一度」は完了履歴・タスク一覧・詳細から1クリックで今日に再登録。タイトル・本文・重要度・資料・関連先をコピーし、元の仕事と時間記録は変更しません。待ち・予定日・定期スケジュール・時間は引き継がず、定期設定を重複作成しません。
- 個別「明日へ繰り越す」と、ホーム「今日の残りを明日へ」（件数確認付き）を追加。元の期限は保持し、作業予定日だけ翌日へ設定。待ちタスクは一括変更の対象外。予定日になるとホームへ戻り、期限切れは期限切れのまま明示します。
- 「週の振り返り」は月曜〜日曜、前週・次週切替。完了日がその週のタスク、週末までが期限で現在も未完了のタスク、記録日がその週の作業別時間と割合。過去時点の未完了スナップショットではなく現在状態です。時間記録はタスク削除後も登録時のタイトルで保持。削除済みタスク自体の完了・未完了一覧は復元しません。未計測時間や完了日不明の旧データを推測して補いません。
- 任意フィールド `status/waitNote/plannedOn/touchedAt`、トップレベル `timeEntries/timer` を追加。保存キー・schema version 1・旧バックアップ互換を維持。バックアップに時間・計測中情報も含めます。全更新は既存の別タブ競合／容量不足保護を経由。他アプリのコード・保存データは変更しません。


## v2.3 毎日のクリック・入力を減らす

- ホームの「タスクを追加」は1行入力へ直接フォーカス。タイトルだけで今日に追加し、Enter後も次を続けて入力できます。期限・資料・繰り返しが必要なときだけ「詳細入力」。タスク一覧の入力途中の文字は再描画でも保持します。
- ホームの各タスクから「着手」「計測／停止」「明日へ」を直接操作できます。詳しい状態や時間修正は従来の「操作」に集約。
- ⠿ をマウス／タッチでドラッグすると今日の作業順を保存。期限グループをまたぐ移動も可能で、「今やる」「次の作業」も追従します。期限切れ・重要度の警告は維持。手動順は当日だけ、翌日は自動順へ戻ります。「自動順に戻す」でも解除できます。
- 「まとめて操作」のときだけチェック欄を表示。ホームとタスク一覧で未完了タスクを選び、一括完了・明日へ繰越・着手可能／待ち／確認待ちへ変更できます。「表示中を全選択」は現在のフィルターで画面に読み込み済みの未完了だけが対象。全件操作には追加表示してください。別の画面・絞り込み・保存更新で選択は解除します。
- 一括繰越も元の期限と待ち状態を保持。計測中のタスクを一括完了・繰越・待ち化すると、計測を一度だけ停止保存します。保存失敗は全件未変更で選択も保持。
- 完了・削除・一括操作・繰越などの直前の変更は「元に戻す」で取り消せます。ホームには取り消しボタンを常設。トーストは12秒で隠れますが、次の保存（利用履歴を含む）・再読み込み・日付変更・別タブ更新までは常設ボタンからも使えます。多段の履歴ではありません。計測中タスクの完了を取り消すと、記録と計測状態もまとめて元に戻します。
- N：ホームの追加欄、/：検索、Ctrl／⌘＋Z：直前の変更を取り消し、Ctrl／⌘＋Enter：選択分を完了、⠿ にフォーカスして Alt＋↑↓：順番変更、Esc：検索・選択解除、?：操作一覧。入力中・IME変換中は通常の文字入力を優先します。
- 「ホームの表示」で進捗・振り返り等のボタン・状況集計・いつもの作業・最近サイト・定型文・メモ・関連アプリの要対応を非表示にできます。データは削除せず、設定画面からいつでも再表示。今日のタスクと計測中の表示は残します。
- 保存キーとschema version 1は維持。任意の `homePrefs` と項目の `homeOrder/homeOrderDay` を追加し、バックアップ往復で保持。繰り返し生成・再登録の新しい仕事には当日の手動順を引き継ぎません。
